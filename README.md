# Calculator

A clean, responsive calculator built with vanilla HTML, CSS, and JavaScript — no frameworks or libraries.

## Features
- Handles operator precedence correctly (× and ÷ before + and −)
- Keyboard support (numbers, operators, Enter to evaluate, Backspace, Esc)
- Live expression preview above the result
- Sign toggle (+/−) and percentage support

## What I learned
Building this helped me understand how to parse and evaluate a string expression
safely, and how to manage UI state without a framework.

## What I'd add next
- Calculation history
- Support for parentheses in expressions
